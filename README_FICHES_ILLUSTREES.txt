G.W².P — PACK FINAL FICHES TECHNIQUES ILLUSTREES

Contenu :
- index.html
- fiches/*.png : fiches techniques illustrées pour les 12 cultures + Papaye
- images existantes du site

Installation GitHub Pages :
1. Remplacer index.html par celui de ce pack.
2. Ajouter le dossier fiches/ à la racine du dépôt.
3. Conserver les images existantes (logo.png, mais.jpg, manioc.jpg, etc.).
4. Ne pas téléverser le ZIP comme seul fichier : GitHub ne le décompresse pas.

Chaque fiche culture est ouverte par le clic sur la culture et présente 13 étapes illustrées :
objectif, sol, implantation, besoins, calendrier, cycle, eau/irrigation, entretien,
organisation, marché/valorisation, partenariat, financement et récolte.
